# Architecture Decision Brief

1. Restate the decision, desired outcome, and known constraints.
2. Identify missing constraints and label necessary assumptions.
3. Use Microsoft Learn tools to verify current capabilities, limitations,
   prerequisites, and operational guidance.
4. Compare two or three viable options against the constraints.
5. Recommend one option and explain why it best fits.
6. Separate Microsoft-documented facts from architectural judgment.
7. If Microsoft Learn cannot verify a current claim, state that limitation.

Return: Decision; Context and assumptions; Options considered;
Recommendation; Trade-offs and risks; Implementation next steps; Sources.

Include relevant https://learn.microsoft.com/ URLs in Sources.
